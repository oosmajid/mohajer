# فروشگاه تلگرامی مهاجر — لیست قابلیت‌ها

این سند نقشهٔ راه بخش فروش ربات است: مشتری داخل همان ربات مهاجر کانفیگ تست می‌گیرد، پلن می‌خرد،
رسید کارت‌به‌کارت می‌فرستد، وضعیت سرویسش را می‌بیند، دوستانش را دعوت می‌کند و اختلال گزارش می‌دهد.
کد مشتری در `bot/shop.py` است و به هستهٔ `bot/bot.py` (ساخت لینک، حجم، زمان، enforcer) تکیه می‌کند.

**راهنما:**
فاز ۱ = نسخهٔ اول · فاز ۲ = بعدی · فاز ۳ = اختیاری ·
**Reply** = دکمه‌های پایین صفحه · **Inline** = دکمه‌های شیشه‌ای زیر پیام · **خودکار** = بدون اقدام کاربر.
اصل UX: ساده و مینیمال، بدون دستور (command) به‌جز `/start` که تلگرام خودش می‌فرستد.
