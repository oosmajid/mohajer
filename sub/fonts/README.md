# Vazirmatn

`Vazirmatn-variable.woff2` is the original variable webfont from
[Vazirmatn v33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003),
downloaded from `fonts/webfonts/Vazirmatn[wght].woff2` without modification.
It includes weights 100–900 and Persian, Arabic, and Latin glyphs.

Copyright 2015 The Vazirmatn Project Authors. Distributed under the SIL Open
Font License 1.1; see `OFL.txt`.

Both panels request the font from `/sub-font-vazirmatn-v33.003.woff2` on their
own host. Keep this directory next to `subserver.py` when deploying.
